Thoth — an After Effects layer management plugin.

Scope control: target the active comp, selected comps, or the whole project.
Toggle selected layers: shy/expose, show/hide, lock/unlock — e.g., quickly hide reference footage before export.
Keyword or null-layer targeting: select layers by name match, or leave blank to grab all null layers, like isolating rig controllers.
Keyframe tools: select keyframed layers, or select keyframes on chosen layers (optionally limited to the work area).
Tag system: apply/clear [tags] and select same-tagged layers for quick organization.

To install:
1. Copy and paste jsx file into your After Effects plugin folder
2. Open the plugin under windows tab in After Effects
